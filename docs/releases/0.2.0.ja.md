# 0.2.0

## Draft 5 Runtime 移行

- AR-XML Core 0.1 Draft 5 の Description Model を追加。
- Issuer-authored AR-DOM と Runtime Evaluation Snapshot を分離。
- Core Structural Validation と opaque Extension Slot 保存を追加。
- Exact identity の Semantic Registry と Contract/Profile Evaluation Port を追加。
- Shared Interface / InterfaceUse routing と Draft 5 HTTP Standard Interface Extension を追加。
- 安定した route handle、明示的な単一 route Invocation、HTTP redirect の fail-closed を追加。
- Capability/Contract Requirement を Runtime state として評価し、公開 Profile 評価を文書全体 evaluator へ統合。
- Draft 4 compatibility を明示的な parser mode に分離し、Profile candidate の順序依存を除去。未解決の narrowing 差分は `UNVALIDATED` に維持。
- 暗黙 Draft 4 grammar の拒否と、Profile candidate 集約の順序非依存を回帰テストで検証。
- Draft 5 適合 fixture と、test・typecheck・build・外部 consumer 検証を必須とする CI を追加。
- 明示的な移行互換経路により Draft 4 隣接文書の読み取りを維持。この経路は Draft 5 conformance の対象外。
