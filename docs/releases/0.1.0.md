# RELink Web Runtime 0.1.0 Release Notes

日本語訳: [日本語版](0.1.0.ja.md)

Release status: **Beta / Experimental**

Runtime `0.1.0` is the first externally distributable release of the RELink Web Runtime. It is intended for evaluation and integration work, not production or safety-critical use.

## Highlights

- Published-package metadata for `@relink/web-runtime`.
- A deliberate public entry point with ESM exports and TypeScript declarations.
- Standalone ESM artifact at `dist/relink-web-runtime.js`.
- Public API Reference covering normal application use, integration ports, data types, and errors.
- A reproducible clean-consumer smoke test covering `npm pack`, tarball installation, TypeScript checking, and Vite production build.

## Specification baseline

Runtime versioning is independent from AR-XML and related specification versions.

| Runtime | AR-XML Core | Resolver Core | Manifest |
| --- | --- | --- | --- |
| 0.1.0 | 0.1 Draft 4 | 0.1 | 0.1 |

## Installation

```bash
npm install @relink/web-runtime
```

```ts
import { ARRuntime } from "@relink/web-runtime";

const runtime = new ARRuntime();
const document = await runtime.load(anchorUrl);
const capability = document.getCapability("temperature");

if (!capability) {
  throw new Error("Capability not found");
}

const result = await capability.invoke({}, { accept: "application/json" });
console.log(result.values.temperature);
```

For a static Web application, copy `dist/relink-web-runtime.js` to a vendor directory and import it as an ES Module:

```html
<script type="module">
  import { ARRuntime } from "./vendor/relink-web-runtime.js";

  const runtime = new ARRuntime();
  console.log(typeof runtime.load);
</script>
```

## Compatibility and responsibility boundary

Versions below `1.0.0` do not guarantee backward compatibility. This release implements the AR-XML Core 0.1 Draft 4 baseline listed above; it does not claim standards compliance.

`ARRuntime.load()` resolves, fetches, parses, validates, and exposes a document. It does not automatically execute Capabilities. Execution is an explicit application or human action through `RuntimeCapability.invoke()`.
