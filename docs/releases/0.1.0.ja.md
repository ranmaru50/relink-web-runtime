# RELink Web Runtime 0.1.0 Release Notes（日本語）

英語正本: [Release Notes](0.1.0.md)

Release Status: **Beta / Experimental**

Runtime `0.1.0`は、RELink Web Runtimeを外部配布可能にした最初のReleaseです。EvaluationとIntegration作業を目的としており、ProductionやSafety-criticalな用途を想定していません。

## Highlights

- `@relink/web-runtime`のPublished Package Metadata。
- ESM ExportとTypeScript Declarationを備えた、明示的なPublic Entry Point。
- `dist/relink-web-runtime.js`として提供するStandalone ESM Artifact。
- 通常のApplication利用、Integration Port、Data Type、Errorを扱うPublic API Reference。
- `npm pack`、Tarball Install、TypeScript Check、Vite Production Buildを含む、再現可能なClean Consumer Smoke Test。

## Installation

```bash
npm install @relink/web-runtime
```

```ts
import { ARRuntime } from "@relink/web-runtime";

const runtime = new ARRuntime();
const document = await runtime.load(anchorUrl);
const capability = document.getCapability("temperature");

if (!capability) {
  throw new Error("Capability not found");
}

const result = await capability.invoke({}, { accept: "application/json" });
console.log(result.values.temperature);
```

Static Web Applicationでは、`dist/relink-web-runtime.js`をVendor DirectoryへCopyし、ES ModuleとしてImportできます。

```html
<script type="module">
  import { ARRuntime } from "./vendor/relink-web-runtime.js";

  const runtime = new ARRuntime();
  console.log(typeof runtime.load);
</script>
```

## Compatibility and Responsibility Boundary

`1.0.0`未満では、Release間のBackward Compatibilityを保証しません。本Releaseは上記のAR-XML Core 0.1 Draft 4 Baselineを実装していますが、Standard Complianceを主張するものではありません。

`ARRuntime.load()`はDocumentのResolve、Fetch、Parse、Validation、Exposeを行います。Capabilityを自動実行しません。Executionは`RuntimeCapability.invoke()`によるApplicationまたはHumanの明示的な操作です。
